# 🧮 Python Calculator

A simple and interactive calculator application built using **Python** and **Tkinter**. This project provides a graphical user interface (GUI) that allows users to perform basic mathematical calculations using clickable buttons or their keyboard.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 📊 Percentage calculations
* 🧹 Clear the entire display
* ⌫ Delete one character at a time
* 🟰 Calculate results instantly
* 🖱️ Interactive GUI buttons
* ⌨️ Keyboard support
* ⚠️ Handles invalid calculations
* 🚫 Handles division-by-zero errors

## 🛠️ Technologies Used

* **Python**
* **Tkinter** – For creating the graphical user interface

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Afrin-D/Python-Calculator.git
```

### 2. Open the project folder

```bash
cd Python-Calculator
```

### 3. Run the calculator

```bash
python calculator.py
```

The calculator window will open, and you can start performing calculations.

## 🎮 How to Use

### Using Mouse

Click the number and operator buttons to enter an expression.

Example:

```text
7 → + → 3 → =
```

Result:

```text
10
```

### Using Keyboard

You can also use your keyboard:

* **Numbers (0–9)** → Enter numbers
* **+ - * /** → Enter operators
* **Enter** → Calculate the result
* **Backspace** → Delete one character
* **Escape** → Clear the display
